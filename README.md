# Eidolon SC 本地客户端

基于 [Sallyn0225/eidolon-sc](https://github.com/Sallyn0225/eidolon-sc) 改编的非官方角色聊天客户端，让《偶像大师 闪耀色彩》的角色对话在本机继续。提供 Android 独立应用与 Windows 桌面适配；聊天使用自己的 API，本地保存记录、档案和长期记忆。

## Android 1.4.4 角色自定义与费用优化

### 可选角色玩法

设置 → 自带密钥 → 角色记忆与好感自定义，两个开关默认关闭。

- **不同角色之间记忆不共享**：普通聊天的本地／云端检索、记忆整理和原生后台主动搭话仅使用当前角色来源的长期记忆，不能修正其他角色的记忆。相同内容按角色分别保存和导入，切换开关清除请求快照与检索缓存；关闭后恢复共享。公共制作人档案、原作资料仍共用，历史聊天中已经出现的内容不会被删除或逆转。
- **好感自由调控**：选择角色设置 0～100 分，可锁定该角色分数、取消每日增长上限，以及在保存时清除冷却、重置当日增长额度。锁定覆盖自然恢复、聊天、礼物、日程及酒吧奖励；关闭总开关后保留分数并恢复原规则。历史成就和已结束对话保留，对话边界判断仍然生效。正在聊天或通话时暂不能修改，避免覆盖进行中的结果。
- 设置和调控数据保存在本机存档，覆盖升级保留。标准数据包仍沿用上游的导出类别，不新增设置／好感编辑器配置的跨设备迁移类别。

### 费用优化

- 设置 → 自带密钥 → 缓存、费用与 API 耗时：默认仅对明确的简单问候、感谢跳过云端检索；具体问题、追问、主动剧情工具和连接测试仍检索。本地模式保持原行为，可关闭优化恢复逐轮检索。
- 云端记忆每 3 轮合并整理；识别到明确记忆要求或个人信息更新时提前处理，前台空闲最多等 90 秒。所有原始消息都会进入持久队列，未匹配提前处理规则的内容仍会被整理。进后台暂停，恢复后继续；失败重试、删除记忆和角色隔离仍生效。本地判断维持逐轮处理。
- 按聊天、检索词、重排、好感判断、记忆及其他请求分别显示最近 100 次调用的缓存、输出 Token 和参考费用。未知用量或单价不算免费；旧记录保留为未分类。原生后台主动消息、语音和图片费用不在此统计内。
- DeepSeek 官方参考单价核对于 2026-10-31，显示空闲至高峰区间，不推断历史账单、节假日或账户优惠；支持按服务商及模型自定义人民币／百万 Token 单价。来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/
- 沿用原包名与签名进行覆盖升级；没有更换聊天模型或自动改动思考参数。使用虚构数据和模拟 API 验证，不承诺固定节省比例。

## Android 1.4.3 正式版

本次整合 1.4.2 / 1.4.3 快照分支，并修复真实界面中大数据包导入卡住的问题。后台解压所需的 Worker 已获页面策略允许，解压超时会退出且保留原存档。导入含主动搭话的旧对话后，列表可以正常显示。系统选择器兼容被文件管理器标为普通二进制的 ZIP，文件内容仍经过完整校验。

- **原正式版用户**：先导出数据包备份，再安装正式 APK 覆盖升级，勿卸载。包名 `local.eidolon.sc.android` 和签名沿用 1.4.1，保留聊天、档案、设置、密钥及已安装模型。
- **独立快照版用户**：快照包名带 `.preview`，与正式版隔离。先在快照版“设置 → 数据包”导出，再在正式版同处导入；核对完成后再自行决定是否卸载快照版。数据包迁移对话、照片、记忆、档案和周期记录，不含 API 密钥、模型文件、独立设置、物品余额、日程和酒吧状态，不能把它当作整个应用的完整备份。
- 正式版支持格式 1、2、3 数据包；重复导入不会重复创建已有对话。损坏或更新格式的包会拒绝，保留原存档。单包最多 200 MB，照片较多时可分开导出。
- APK 约 270 MB，不含可选模型权重。模型与 `1.4.2-preview.1` 发布的三个模型包相同，已有包无需重下；从[模型包发布页](https://github.com/ghshshshhsua/eidolon-sc-releases/releases/tag/v1.4.2-preview.1)下载，按需在“设置 → 自带密钥 → 语义检索与本地模型”导入。新装未导入模型时只能使用已配置的相应云端功能，不会擅自切换到付费 API。
- 更新检查使用正式通道；快照版为避免签名和包名混淆，仍不提供正式版覆盖更新。

同步上游 `c4bd0b5` 的日程、周期、体贴判定、暖礼物与 VA-283 酒吧，成就页替代每日任务；保留前缀缓存、检索缓存、并行判断和流式输出。酒吧原版音乐未打包。Windows 仍为 0.7.1，本次没有发布新的 Windows 补丁。

验证：1,458 项前端测试、上游行为对齐、缓存/检索/语音协议回归、TypeScript、Vite、Android release 构建与 lint、模型导入器校验。生产页面策略下导入旧版真实导出的虚构记录及大存档通过；Android 测试模拟器上覆盖 1.4.1、保留 SQLite/Keystore、系统文件选择及大存档导入通过。没有使用个人存档或付费模型；实体手机的速度、音质和特定文件管理器行为仍需实测。

## Android 1.4.2 响应、缓存与轻量安装包

- APK 默认排除 Qwen、E5／mmarco、语义向量索引和 Vosk 模型，模型分为三个可复用 ZIP 包。设置 → 自带密钥 → 语义检索与本地模型 → 导入独立模型包；按需选择 Qwen、检索或语音包。只使用云端功能时可不导入模型，在设置中选择相应 API 模式（额外调用可能计费）。
- 覆盖升级保留已经解压并校验的旧模型；模型未曾初始化或更换时需导入匹配包。导入前校验包内完整组、大小和 SHA-256，校验失败不替换旧模型。模型不随聊天存档导出；卸载应用将清除模型。
- 将时间、档案、关系、记忆和本轮检索资料移至历史对话之后，避免它们每轮变化时打断角色设定和历史的公共前缀。照片权限与输出格式规则仍保留在系统指令中。
- 长对话按六条消息分批淘汰旧记录，保留有界的 30–35 条历史，减少逐轮滑动导致的缓存失效。
- 检索与独立判断并行安排；聊天流式输出不再等待判断完成，最终好感度和存档仍等待判断结果。取消和失败会停止本轮未完成的判断。
- 前台新消息立即让本地后台记忆任务让出推理队列；云端记忆整理独立完成，不再额外等待五秒。被中断的本地任务保留在队列中重试。
- 实际缓存命中率、首字延迟仍取决于 API 服务商、模型、网络和缓存保留策略；未承诺具体百分比或真机加速倍数。构建签名 APK 仍需恢复公开资源并使用维护者的原签名。

## 功能使用入口（含 1.4.1 修复）

- 修复手机检查更新返回 HTTP 403：优先读取 GitHub 公开版本文件，失败时使用 GitHub API。API 限流时按响应头等待，不需要 GitHub 登录或令牌。检查失败后仍能打开发布页下载，自动检查失败五分钟后可重试。旧版更新入口已被拒绝时，可从公开 Release 手动下载并覆盖安装。

- 检索：设置 → 自带密钥 → 语义检索与本地模型，可选“云端 · 沿用聊天 API”。已另配后台模型时优先使用后台模型，否则使用聊天模型；不会启动本地 E5 / mmarco。
- 官方 DeepSeek 的检索请求关闭思考、启用 JSON 输出并保留足够输出额度，整个云端检索最多等待 45 秒；聊天设置保持原样。其他兼容接口保持原参数，使用思考模型时建议另配非思考后台模型。
- 点击“测试当前检索”可检查同一条完整检索流程。测试发送公开示例及公开角色资料，不发送聊天记录或个人记忆，会调用 API，可能计费。状态显示具体失败阶段；聊天失败时继续用关键词备用检索，成功重试后清除旧状态。
- 云端检索采用关键词初筛后语义排序，关键词没有命中的资料仍可能遗漏；不要求给全量资料建立付费云端向量索引。也可单独配置 `/rerank` 专用模型，需使用该服务商自己的密钥。
- 离线语音：设置 → 通话 → 语音识别，选择“应用内离线识别 · 中文”。独立 Vosk 轻量普通话模型包，不依赖系统识别服务，也不需要语音 API Key。首次使用会解压模型；适合安静环境中的普通话短句，专有名词、噪声和口音会影响准确率。
- 旧设置若保留“系统识别”，当系统服务缺失或识别失败时，中文自动改用内置离线模型。系统离线引擎不可用不代表内置模型不可用；界面分开显示。
- 日语、英语或更高识别质量可选择系统或云端识别。云端识别默认示例为硅基流动 SenseVoiceSmall，需另填相应密钥；不会自动发送语音到云端。
- 录音仅在内存暂存，停顿后识别，单段最多 15 秒；不会保存录音文件。挂断、暂停麦克风和切后台后丢弃迟到结果。离线识别不联网，云端识别会发送音频片段给所选服务商。
- 如果仍受本地 Qwen 等待影响，可把“独立判断和记忆整理”也切到 API，会另外调用模型计费；该模式不运行本地表情分类，立绘使用默认表情。

[DeepSeek 思考开关](https://api-docs.deepseek.com/guides/thinking_mode/) · [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/) · [Vosk 官方模型与许可](https://alphacephei.com/vosk/models)。云端速度、费用和实体手机识别效果需自行配置后实测。

## 项目内容

| 功能 | 实现方式 |
| --- | --- |
| 29 位角色聊天 | 原项目人设、公开剧情资料与对话上下文，支持流式中日文回复 |
| 聊天模型 | 自行填写 DeepSeek 或兼容接口；没有内置聊天大模型或服务商密钥 |
| 语义检索与重排 | 本地 E5 / mmarco，或快速关键词召回 + 云端语义筛选 |
| 判断与长期记忆 | 本地 Qwen3-1.7B，可在设置中选择 API 判断 |
| 立绘与互动 | 动态立绘、好感度、礼物、任务、日历和统计 |
| 语音 | Android 可选离线中文模型包、系统或云端识别、可见状态与重试、Fish Audio 角色音色；Windows 另有本地合成适配 |
| 照片与主动搭话 | 配置生图接口后按请求生成；主动搭话需手动开启，可能产生 API 费用 |
| 本机存档 | 聊天、记忆、档案和数据包导入导出；密钥使用系统安全存储 |
| 更新检查 | 关于页面手动检查、每天一次启动检查、版本说明与下载入口 |

角色还原依赖人设、检索到的剧情和记忆共同组织提示词，由所选聊天 API 生成回复。它不是针对每位角色单独训练的聊天模型，效果会受服务商模型和上下文影响。

## 安装与使用

在[公开发布页](https://github.com/ghshshshhsua/eidolon-sc-releases/releases)下载对应文件。

Android 安装 APK 后，在“设置 → 自带密钥”填写聊天接口和模型名；Fish Audio 密钥可稍后添加，不配置时使用文字聊天。最低 Android 8.0 / ARM64，建议保持系统 WebView 更新。1.4.2 起 APK 与模型分开发行。三个模型包共约 1.85 GB（未压缩），按功能选装；导入需要暂存空间，全部安装建议预留 8 GB。APK 实际大小以签名构建产物为准。NNAPI / Vulkan 是否可用取决于设备和驱动，设置中显示实际后端与回退情况。第三方 ORT Extensions 仍有 16 KB 页兼容限制，不能保证所有设备可用。

Windows [0.7.1 更新补丁](https://github.com/ghshshshhsua/eidolon-sc-releases/releases/tag/v1.2.1)适用于已有本地版，不是首次安装器。先退出应用，把更新包内文件覆盖到原 Eidolon-SC 应用目录，再用原入口启动。不要替换或删除 data 目录；补丁不包含记录、密钥或本机运行环境配置。

首次需手动安装带更新入口的版本。Android 在“设置 → 关于 → 应用更新”，Windows 在“连接设置 → 应用更新”检查。启动检查每天最多一次，可关闭；只获取版本元数据，不自动下载、替换或安装。发现新版后打开公开 Release，下载并按系统提示操作。Android 使用相同签名覆盖安装，先导出数据包备份，勿卸载旧版。

## 隐私与数据去向

记录保存在设备。聊天上下文、相关剧情和记忆会发送给你配置的聊天 API；Fish Audio 接收待合成文本；生图服务接收相应提示词。安装模型后的中文语音识别在手机离线处理；选择系统或云端识别时，音频可能发送给相应服务商。

更新检查访问公开 GitHub 清单，不携带账号令牌、聊天记录、API 密钥或设备标识。网络服务仍会接收建立连接所需的常规网络信息。源码和发布包排除个人聊天、账号配置、签名私钥、日志、浏览器资料和本机编译路径；不预装任何个人存档。

## 源码结构与构建

- work/android-app：Java 原生桥接、SQLite / Keystore、模型推理与 Android React 界面。
- work/source/eidolon-sc-main：原项目前端、后端与角色公开配置，保留本地适配。
- outputs/Eidolon-SC/desktop：Electron 窗口、连接设置、更新检查。
- outputs/Eidolon-SC/local：Windows 本地推理与后端适配。

安装 Node 24、JDK 25、Android SDK Platform 36 / Build Tools 36.0.0，设置 JAVA_HOME 和 ANDROID_HOME。完整对应源码包保留公开模型、索引、JNI 和 AAR；解压后执行 work/android-app/build.ps1。Git 开发仓库省略大模型与生成资源，可先从对应 Release 的源码包恢复这些内容。签名私钥始终由维护者本机保管；自行签名的 APK 不能覆盖原签名安装。

重建 JNI 使用 NDK 29.0.14206865 / CMake 3.31.6；运行 work/prepare-android-vulkan-tools.py 和 work/build-android-judge.ps1。llama.cpp 固定来源和 Android 补丁见 cpp/llama-source.json。编译启用路径映射，避免把开发者本机路径带入原生库。

独立模型包：恢复公开模型资源后运行 `python work/build-model-packs.py --output model-packs`（Python 3.11+）。包名按模型内容标识，应用升级无需重新发布未变化的模型包；构建脚本无论资源是否存在都从 APK 中排除模型二进制。

源码验证：`node work/test-performance.cjs`、`python work/test-model-packs.py`；用 JDK 17+ 编译运行 `work/tests/ModelPackInstallerTest.java` 与 `ModelPackInstaller.java`；node work/test-update-check.mjs；安装前端依赖后运行 TypeScript 检查、Vite 构建、Android assemble / lint。更新界面测试 node work/test-update-ui.cjs 使用临时浏览器数据和模拟更新信息；云端模型与语音回归见 work/test-cloud-models.cjs、test-cloud-ui.cjs 和 test-cloud-native.cjs，不使用真实付费 API。Windows 首次部署仍需自行准备 Python / Electron 与本地模型环境，runtime.json 不随公共发布包分发。
